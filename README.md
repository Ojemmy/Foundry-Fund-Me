# Foundry Fund Me

## About

Foundry Fund Me is a decentralized crowdfunding smart contract built with Solidity and Foundry. It allows users to fund a contract with ETH while tracking individual contributions.

The project demonstrates core smart contract development concepts, including payable functions, mappings, custom errors, Chainlink price feeds, and automated testing.

## Requirements

Before getting started, make sure you have:

- [Git](https://git-scm.com/)
- [Foundry](https://getfoundry.sh/)
- An Ethereum RPC URL (needed for network interactions)

## Quick start
git clone https://github.com/Ojemmy/Foundry-Fund-Me
cd Foundry-Fund-Me
forge build

## Technologies Used

- Solidity
- Foundry
- Chainlink Price Feeds
- Ethereum
